## 2. 評価ロジック設計

### TED基準の4項目評価ルール

**Emotion（感情）** - キーワードマッチング
- 高スコア: 「感動」「驚き」「不安」「喜び」「怒り」「悲しみ」「体験」「実話」
- 中スコア: 「思い」「気持ち」「感じ」
- 低スコア: データや事実のみ

**Novelty（意外性）**
- 高スコア: 「しかし」「実は」「意外にも」「驚くべき」「常識とは逆」「新発見」
- 中スコア: 「新しい」「違う」「変化」
- 低スコア: 一般的な内容

**Memorability（記憶に残る）**
- 高スコア: 「たった〇〇で」「○○倍」「数字」「具体例」「比喩」「ストーリー」
- 中スコア: 事例や例え話
- 低スコア: 抽象的な話のみ

**Storytelling（ストーリー性）**
- 高スコア: 「昔」「ある日」「最初は」「そして」「最終的に」時系列
- 中スコア: 経験談や事例
- 低スコア: 箇条書きや説明のみ

### TEDトーカー診断ロジック
- **サイモン・シネック型**: 「なぜ」「理由」が多い
- **スティーブ・ジョブズ型**: 「革新」「変える」「シンプル」
- **エイミー・カディ型**: 「身体」「姿勢」「変化」「実験」
- **ブレネー・ブラウン型**: 「弱さ」「勇気」「恥」「つながり」

## 3. 技術構成

### ファイル構成（Next.js）
```
src/
├── app/
│   ├── page.tsx              # メインページ
│   ├── layout.tsx            # レイアウト
│   └── globals.css           # グローバルスタイル
├── components/
│   ├── InputForm.tsx         # 入力フォーム
│   ├── ScoreDisplay.tsx      # スコア表示
│   ├── SuggestionCard.tsx    # 改善提案
│   └── SpeakerType.tsx       # TEDトーカー診断
├── utils/
│   └── analyzer.ts           # 評価ロジック
└── data/
    ├── keywords.ts           # キーワード辞書
    └── speakers.ts           # スピーカー情報
```

### 状態管理（useState）
```typescript
const [inputText, setInputText] = useState('')
const [analysis, setAnalysis] = useState(null)
const [isAnalyzing, setIsAnalyzing] = useState(false)
```

### スタイリング方針
- **Tailwind CSS**: ユーティリティクラス中心
- **カラー**: TED風の赤系（#e62b1e）をアクセント
- **レイアウト**: max-w-4xl mx-auto でセンタリング
- **レスポンシブ**: なし（PC向けのみ）
