# 仕様書: TED式 プレゼン指南所

**プロダクト名**: TED式 プレゼン指南所  
**コンセプト**: あなたの資料を"世界最高のプレゼン基準"で添削

## プロトタイプの最小機能（MVP）

### 🎯 コア機能: TED基準レビュー（簡易版）
- **テキスト入力フォーム**: プレゼン内容をテキストで貼り付け
- **TED基準での自動評価**: 
  - Emotion（感情を揺さぶっているか）
  - Novelty（驚き・意外性はあるか）  
  - Memorability（記憶に残るか）
  - Storytelling（ストーリー性があるか）
- **スコア表示**: 各項目を5段階で評価
- **改善提案**: 簡単なフィードバックメッセージを表示

### 🎭 サブ機能: TEDトーカー診断
- **診断結果表示**: 有名なTEDスピーカーに例えて結果表示
- **スタイル分析**: 「サイモン・シネック型」「スティーブ・ジョブズ型」など

## プロトタイプ開発方針
- **ペライチ構成**: 1画面で入力→結果表示まで完結
- **AI連携なし**: 事前に用意したルールベースで評価（GPT API使わない）
- **データ保存なし**: セッション内で完結、リロードで消える
- **シンプルUI**: 基本的なフォームとカード表示のみ

## やらないこと（プロトタイプでは）
- PDF/スライドファイルのアップロード
- 実際のAI（GPT-4/Claude）連携
- ユーザー認証・データ保存
- ストーリーボード変換
- 音声読み上げ機能
- レスポンシブ対応

## 技術構成
- **フレームワーク**: Next.js
- **スタイル**: Tailwind CSS
- **評価ロジック**: JavaScriptの条件分岐（キーワードマッチング）
- **データ**: 静的な評価ルールとメッセージ
