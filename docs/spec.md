# 機能要件書 - TED式 プレゼン指南所

**重要**: このプロジェクトはプロトタイプ開発がメインです。完璧さよりも動作を優先し、ペライチのサイトが作れればOKです。

## プロジェクト概要
**サービス名**: TED式 プレゼン指南所  
**コンセプト**: ユーザーのプレゼン資料をTEDトークの手法に沿ってレビューし、「伝わる・響く・覚えてもらえる」プレゼンにブラッシュアップする

## 基本的な機能（プロトタイプ版）
- **テキスト入力**: プレゼン内容をテキストエリアに入力
- **TED基準レビュー**: Gemini APIでレビュー実行
- **結果表示**: レビュー結果をシンプルに表示

## TED基準レビュー機能（最優先）
**レビュー観点**:
- Emotion（感情を揺さぶっているか）
- Novelty（驚き・意外性はあるか）
- Memorability（記憶に残るか）
- Storytelling（ストーリー性があるか）
- 18分以内で語れる構成か（TED流の時間感覚）

**出力**: 各観点のスコアと改善ポイント

## 開発方針
- **とにかくシンプル**: テキスト入力→レビュー実行→結果表示のみ
- **雑でもOK**: 完璧さよりもスピード重視
- **ペライチ**: 1画面で完結する構成
- **Gemini API**: レビュー機能のみ実装

## やらないこと（プロトタイプでは）
- ファイルアップロード機能
- TEDトーカー診断
- ストーリーボード変換
- ナレーション生成
- データベース連携
- ユーザー認証
- 高度なアニメーション
- パフォーマンス最適化

## 技術制約
- **フレームワーク**: Next.js
- **API**: Gemini API
- **スタイル**: シンプルなCSS（Tailwind CSS推奨）
